# ✨ Happy Birthday Arooj — Celestial Celebration Experience

A high-end, interactive 3D birthday celebration web experience created with eternal love by **Shafi** for **Arooj**.

---

## 🌟 Features & Highlights

- **Cinematic Red Rose Intro**: Fullscreen celestial cloud video with scroll-controlled stage progression and smooth play/pause response.
- **Stage 2 ("In a World of Billions...")**: Authentic animated background video with orbiting 3D photo medallions.
- **Stage 3 ("Touch & Hold to Connect")**: Interactive Michelangelo-inspired creation hands with dynamic time-passing cycle (dawn to golden sunset to starlight), pulse aura rings, and glass-shattering transition flash.
- **Celebration Climax Soundtrack**: Seamlessly starts playing *"Him & I (Siimi Remix)"* upon completing the connection, accompanied by golden celestial confetti bursts.
- **Interactive Birthday Cake**: Light/blow candles with realistic flickering flame glow, blessings, and celebratory confetti cannon.
- **Memories Polaroid Gallery**: 3D parallax tilt polaroid cards with lightbox inspection.
- **Video Theater**: Obsidian-gold glass cards playing cherished moments.
- **Interactive 3D Flip Cards (01–06)**: Six reasons of admiration with golden cursive typography.
- **Personal Love Letter**: Beautiful wax-sealed letter written in heartfelt Roman Urdu.
- **Persistent Floating Dock & Sound Controls**: Quick navigation, replay buttons for Rose Intro and Tap & Hold, and live audio visualizer.
- **Warm Celestial Sunset Gold & Velvet Rose Theme**: Deep royal twilight velvet obsidian (`#0C0811`), radiant sunset gold (`#FFE29A`), warm amber (`#F59E0B`), and velvet rose blush (`#FF758F`).

## 🚀 Running Locally

No heavy installations required. Runs using native Node.js:

```bash
# Clone the repository
git clone https://github.com/vantraxotech-collab/birthday.git

# Navigate to project folder
cd birthday

# Start the local server
node server.js
```

Open your browser at **`http://localhost:3000`** to experience the celebration.
